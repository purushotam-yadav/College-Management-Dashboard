# College Management Dashboard

## Project Overview
An interactive College Management Dashboard developed using Microsoft Power BI to analyze and visualize college data.

## Key Performance Indicators
- Total Students
- Total Faculty
- Total Courses
- Total Departments
- Total Subjects
- Total Exams
- Average Marks
- Attendance Percentage

## Dashboard Features
- Students by Department
- Students by Course
- Grade Distribution
- Students by Semester
- Attendance by Status
- Average Marks by Department
- Students by Gender
- Topper Students List

## Interactive Filters
- Department
- Course
- Semester
- Gender
- Students ID

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis
